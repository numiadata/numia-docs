# Onchain CRM

![Numia Onchain CRM](/media/onchain-crm.png)

Numia's Onchain CRM is a Web3-native customer relationship management platform built to help blockchain projects, protocols, and L1/L2 networks understand, segment, and engage their users at the wallet level. Transform raw blockchain data into actionable insights for growth.

## Overview

Traditional CRMs are built for Web2 with emails and user accounts. In Web3, your users are wallets—pseudonymous, multi-chain, and defined by on-chain behavior. Numia Onchain CRM provides a unified view of users across chains, combining on-chain data with off-chain signals to power data-driven decisions.

## Core Features

### Unified Wallet Database
Every wallet profiled with comprehensive attributes including trading activity, engagement metrics, cross-chain behavior, DeFi interactions, risk indicators, and off-chain enrichment (social profiles, ENS, developer activity).

### Interactive Dashboard
- Visual database explorer with search and filtering
- Advanced segmentation and cohort analysis
- Custom report builder with export capabilities
- Visual analytics with charts and retention curves

### API Access
- REST API for wallet profiles (single or batch queries)
- Segmentation API for targeted exports
- Webhook support and real-time data access
- API key management with role-based access control

### Custom Attributes
Define custom wallet attributes including derived metrics, behavioral tags, and predictive scores (churn risk, LTV predictions, engagement propensity).

## Use Cases

**L1/L2 Networks**: Track ecosystem health, monitor validators, identify contributors, measure cross-chain adoption.

**DeFi Protocols**: Re-engage dormant users, profile liquidity providers, monitor whale activity, optimize incentive programs.

**Token Projects**: Build community, analyze holder distribution, track governance participation, optimize tokenomics.

**Marketing Teams**: Export segmented addresses, personalize campaigns, track acquisition channels, measure product-market fit.
